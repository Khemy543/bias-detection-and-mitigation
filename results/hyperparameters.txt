══════════════════════════════════════════════════════════════════════
  ALGORITHM 1 — PRE-PROCESSING (Reweighing + SMOTE)
══════════════════════════════════════════════════════════════════════

Reference: Kamiran & Calders (2012)

Reweighing
  Formula         : w(a,y) = P(A=a) * P(Y=y) / P(A=a,Y=y)
  Sensitive attr  : Gender (0 = Female, 1 = Male)
  Label           : Selected (0 = not selected, 1 = selected)
  Applied to      : fit split (60% of data) and full training set

SMOTE (Synthetic Minority Over-sampling Technique)
  k_neighbors     : 5 (imbalanced-learn default)
  random_state    : seed
  Applied to      : reweighed fit split and full training set

Synthetic sample weighting
  Weight assigned to synthetic samples : mean weight of original
                                         positive-class samples


══════════════════════════════════════════════════════════════════════
  ALGORITHM 2 — IN-PROCESSING (Fairness-Constrained Training)
══════════════════════════════════════════════════════════════════════

  λ (lambda, fairness penalty weight)  : 1.0
  N_ITER (max iterations)              : 3
  Early stopping threshold             : disparity < 0.01
  Initial sample weights               : all ones (uniform)

  Per iteration:
    1. Fit model with current sample weights
    2. Compute per-group positive rates
    3. disparity = max_rate − min_rate
    4. If disparity < 0.01 → stop early
    5. Upweight false negatives in disadvantaged group (Female):
         weights[FN_female] += λ * disparity
    6. Upweight false positives in advantaged group (Male):
         weights[FP_male]   += λ * disparity
    7. Normalise: weights = weights / mean(weights)

  Applied to: fit split (for calibration model) and full training set


══════════════════════════════════════════════════════════════════════
  POST-PROCESSING — Group-Specific Threshold Optimisation
══════════════════════════════════════════════════════════════════════

  Threshold grid    : np.linspace(0.01, 0.99, 99)  [99 candidate thresholds]
  Search space      : all combinations of thresholds per group (grid²)
  Optimised on      : calibration set (20% of training, held out)

  Objective function (minimise):
    di_penalty + EOD + 0.5 * DPD

    where:
      di_penalty = max(0.0, 0.80 − DI) * 5
      DI  = min(group_rate) / max(group_rate)
      EOD = max(|TPR_F − TPR_M|, |FPR_F − FPR_M|)
      DPD = max(group_rate) − min(group_rate)

  Constraints:
    min overall positive rate : 0.125  (= TARGET_POS_RATE * 0.5)
    max overall positive rate : 0.375  (= TARGET_POS_RATE * 1.5)

  Legal DI threshold          : 0.80
  Target positive rate        : 0.25

══════════════════════════════════════════════════════════════════════
  FAIRNESS METRIC DEFINITIONS
══════════════════════════════════════════════════════════════════════

DI  (Disparate Impact)
  DI = min_group_selection_rate / max_group_selection_rate
  Legal threshold: DI ≥ 0.80  (80% rule, EEOC guidelines)

DPD (Demographic Parity Difference)
  DPD = max_group_selection_rate − min_group_selection_rate
  Target: DPD = 0  (perfect parity)

EOD (Equalized Odds Difference)
  EOD = max(|TPR_F − TPR_M|, |FPR_F − FPR_M|)
  Target: EOD = 0  (equal true-positive and false-positive rates)

Sensitive attribute : Gender  (0 = Female, 1 = Male)
